# Development Tools

This directory contains utility scripts for development, testing, and analysis.

## Scripts

### cleanup.py

Utility for cleaning up generated files, temporary data, or cache files.

**Usage:**

```bash
python tools/cleanup.py
```

### results.py

Script for analyzing, processing, or visualizing results from coverage planning runs.

**Usage:**

```bash
python tools/results.py
```

### run_all.py

Batch processing script to run the pipeline on multiple maps or configurations.

**Usage:**

```bash
python tools/run_all.py
```

## Notes

- These tools are not part of the main `covpp` package
- They are development utilities for testing and analysis
- Not included in package distribution (see `MANIFEST.in`)
